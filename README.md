# Developer Tools Hub

这是一个适合部署到 GitHub Pages 的静态开发工具站点骨架。

## 结构说明

- 首页：`index.html`
- 工具页面：`tools/<tool-name>/index.html`
- 共享样式：`styles.css`

## 发布到 GitHub Pages

1. 将代码推送到 GitHub 仓库。
2. 在仓库设置中开启 GitHub Pages。
3. 选择 `main` 分支的根目录作为发布源。
4. 访问 `https://<username>.github.io/<repo>/`。

## 当前已包含的示例工具

- JSON 格式化
- Base64 编解码
- UUID 生成
